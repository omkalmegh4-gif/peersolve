> *"Ask questions, share knowledge, and learn together."*  
> **PeerSolve** is a collaborative academic discussion and doubt-resolution platform where students connect to ask complex academic queries, exchange structured solutions, and elevate peer learning across disciplines.

---

## 🌟 Key Features

- **❓ Ask & Clarify Doubts**:
  - Structured doubt submission form supporting subject categories, detailed descriptions, and code/concept tags.
- **📚 Question Feed & Discovery**:
  - Browse questions across diverse subjects and academic departments.
  - Filter by status (resolved, awaiting answer) and search topics quickly.
- **💡 Collaborative Peer Answers**:
  - Provide solutions and explanations to help classmates and peers.
  - Mark answers as verified and build collaborative subject mastery.
- **👤 Student Profile & Dashboard**:
  - Track asked questions, answered queries, and academic engagement.
  - Built-in authentication views (Sign In & Sign Up flows).
- **📱 Clean Modern UI**:
  - Purpose-built academic dashboard layout with responsive sidebar navigation and minimal distraction design.

---

## 🛠️ Tech Stack

- **Markup**: HTML5
- **Styling**: CSS3 (Modern Dashboard Layouts, Flexbox, Responsive Cards)
- **Client Logic**: Vanilla JavaScript (SPA View Switching, Question Feed State, Modal Controls, Profile State)

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/omkalmegh4-gif/peersolve.git
cd peersolve
```

### 2. Run the application
Open `index.html` in your browser, or start a local dev server:
```bash
# Using Python
python -m http.server 3000
```
